PlanRadar is a SaaS platform for construction and real estate documentation, defect and task management, and site inspections, used by builders, owners, facility managers, architects and engineers in more than 75 countries. Its secure REST Open API (v1 and v2) lets Pro and Enterprise customers read and manage projects, tickets, documents, DMS nodes, forms, plans, roles, approval requests and workflows, and Site View captures, generate asynchronous Excel and PDF exports, and subscribe to event webhooks. PlanRadar Connect, built on Workato, layers 200+ no-code integrations on top of the API for tools such as SharePoint, Power BI, Salesforce, Procore, SAP, Jira and Slack.

**Areas:** Company · Construction · Real Estate · Project Management · Documentation · Defect Management · Field Service Management · Facility Management · BIM · Software-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for PlanRadar: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
