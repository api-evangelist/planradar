# PlanRadar

> PlanRadar is a SaaS platform for construction and real estate documentation, defect and task management, and site inspections, used in 75+ countries. Its secure REST Open API (v1 and v2, scoped by customer_id) covers projects, tickets, documents, DMS, forms, plans, roles, approval workflows, Site View, exports and webhooks. Authentication is an API key (Personal Access Token) sent in the X-PlanRadar-API-Key header; the account rate limit is 30 requests per minute.
